# Reframe — 利用規約・プライバシーポリシー

iOS / Android アプリ「Reframe」の法的文書を GitHub Pages で公開するためのリポジトリです。

- [利用規約](https://satosato-mech.github.io/reframe-legal/terms.html)
- [プライバシーポリシー](https://satosato-mech.github.io/reframe-legal/privacy.html)

これらの URL は、アプリ内のペイウォールと App Store Connect / Google Play Console の
両方から参照されています。**リンク切れは審査のリジェクト理由になる**ため、
リポジトリ名やファイル名を変更する場合は、参照側（`reframe-expo` の `src/links.ts`）も
同時に更新してください。

## 原稿の管理について

HTML の原稿（Markdown 版）と、App Store Connect のカスタム使用許諾契約欄に貼る
プレーンテキスト版は、アプリ本体のリポジトリ `reframe-expo` の `docs/` にあります。
**内容を変更するときは、そちらを直してから、このリポジトリの HTML を更新してください。**
